## 1. 模块化与实线直连原则

- **真实信号流排版**：页面内按主信号流（通常左 → 右）及电源层级分区排版，并绘制模块框与简短中文功能说明，使架构与流向一目了然。
- **模块内部全正交实线直连**：阻容、偏置分压、反馈/伺服、环路滤波、端接、电荷泵飞跨电容（如 `U304` 与 `C322`）及退耦电容必须使用正交 `Wire` 实线直连到 IC 引脚，禁止用 `NetPort` 把单颗阻容拆成孤立碎片。
- **并联退耦电容组**：采用“上电源横线 + 下地横线 + 单一朝下 `GND`”的汇流排拓扑。
- **模块间与跨页连接**：仅跨模块框、跨图页或往返主控（如 `H1`）/外部接插件信号使用 `NetPort`。
- **无源器件显示值简写**：所有 `R*` / `C*` / `L*` 显示 `Name` 统一简化为直观数值（如 `100nF`、`10kΩ`、`49.9Ω`），保留原厂与商城料号属性。

## 2. 单端符号方向铁律（`BBox Away-From-Wire`）

所有单端符号的图形包围盒（`getPrimitivesBBox`）必须严格位于锚点 `(x, y)` 背离来线方向的外侧空白区：

- **`Ground` 符号**：固定 `rot = 0`（朝下，导线仅可从上方垂直接入）。
- **`Power` 符号**：固定 `rot = 0`（朝上，导线仅可从下方或水平接入，严禁从上方穿字接入）；相邻同高（`Δy < 25`）`Power` 符号水平中心距 `≥ max(70, 字符数 × 8 + 20)` units，距旁侧平行竖线 `≥ 25` units。
- **`createNetPort(dir, net, x, y, rot, false)` 方向表（实测 `IN` 与 `OUT`/`BI` 锚点相反）**：
  - `OUT` 与 `BI` 的连接锚点在**尾部**；
  - `IN` 的连接锚点在**箭头尖端**。

| 端口所在模块侧（来线方向） | `OUT` / `BI` raw `rot` | `IN` raw `rot` | 效果（本体严格在外侧空白区） |
|---|---|---|---|
| **模块右侧**（导线从左向右接入） | `0` | `180` | `───(x,y)──▷` / `───(x,y)──◁` |
| **模块左侧**（导线从右向左接入） | `180` | `0` | `◁──(x,y)───` / `▷──(x,y)───` |
| **模块上方**（导线从下向上接入） | `90` | `270` | 本体严格位于 `y` 上方 |
| **模块下方**（导线从上向下接入） | `270` | `90` | 本体严格位于 `y` 下方 |

## 3. 严格“一网一标”防双标签铁律

EasyEDA Pro 系统库中 `Netport-IN` 与 `Netport-OUT` / `Netport-BI` 的内置文字渲染行为完全不同：

1. **电源 / 地支路**：所有连接 `Power` / `Ground` 旗标的导线，一律传 **`net = None`**（禁止再在导线上写 `'GND'` 或电源名导致双标签）。
2. **`Netport-IN` 支路**：系统库 `Netport-IN` 符号**自带蓝色网络名文字**（渲染在五边形尾端外侧）。凡连接 `Netport-IN` 的导线**一律传 `net = None`**（若导线也传 `net` 必出双份重影标签），并在五边形外侧留足文字空白区（避免压到相邻元器件）。
3. **`Netport-OUT` / `Netport-BI` 支路**：系统库 `OUT` / `BI` 符号**不自带网络名文字**（仅画空五边形）。因此每条 `OUT` / `BI` 分支必须在**唯一一段无遮挡纯水平导线**上赋 `net = '<NET>'`（该水平段长度 `≥ max(85, 字符数 × 8 + 25)` units，且距上下平行导线 `≥ 20` units）。禁止全段不传 `net`（变空白五边形），也禁止把同一水平线拆成两段共线相连并分别赋名（必出双标签）。
4. **模块内纯内部网络**：仅允许在唯一一段无遮挡水平长线（长度 `≥ 60`、上下净空 `≥ 18` units）上赋 `net`；短于 `60` units 的二端串联短跳线或垂直狭窄段一律传 `net = None`。

## 4. 零共线重合、零穿模与密集引脚阶梯扇出

- **严禁无交点信号线共线重合**：任何两根 `Wire`（尤其不同网络）不得在同一 `X` 或 `Y` 直线上区间重叠；不同网络共线端点间距 `≥ 20` units（Linter 硬门限 `≥ 15` units）；平行不同网络导线正交间距 `≥ 15` units。
- **10-unit 密集引脚阶梯扇出**：严禁在 `10-unit` 垂直间距下直接堆叠水平带标签线或 `NetPort`。必须先用正交 L 形折线将相邻分支的 Y 坐标拉开至 `≥ 20–30` units，且外层纯水平标签段长度必须明显大于内层 `10u` 间距引出段（例如 `H1` 外段 `190u` vs 内段 `≤ 140u`），使 EasyEDA 自动将标签居中渲染在宽间距外段上。
- **走线禁穿器件与图元 BBox**：走线严禁穿过 IC/阻容/接插件本体、位号/数值文字或 `NetPort` / `NetFlag` 的 `getPrimitivesBBox` 内部。
- **安全读取、清理与删除机制**：
  - `w.getState_Line()` 返回 4 元分段数组 `[x0, y0, x1, y1, ...]`（`len % 4 == 0`），解析几何时须按步长 `4` 切分，不可按连续折线步长 `2` 解析。
  - **严禁调用 `eda.sch_Netlist.getNetlist()` / `getNetlistFile()`**（会静默重排全工程位号），统一使用只读元件引脚查询 + 并查集连通性验证。
  - **清理旧线防卡死与残留**：重布区域须按几何坐标与关联网络动态 re-query `eda.sch_PrimitiveWire.getAll()`，分小批（`≤ 4–5` 个）逐 ID 调用 `.delete(id)`，并用 `Promise.race([..., 1500ms])` 包裹单次调用（禁止传数组，也不得在连续删线途中对可能已被自动合并消除的旧 ID 调用未保护的 `.get(id)`）。
  - **不要对稳定页面反复 `deleteSchematicPage`**：EasyEDA 内部会缓存已删页名称导致同名重建失败；微调坐标应在当前页面就地删改对应图元并 `save()`。
