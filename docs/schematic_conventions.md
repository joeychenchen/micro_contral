# Learning Proposal: 端口/符号方向防穿模与全局图元防重合通则（以此类推完善版）

## 1. 根因复盘（结合截图中 `ADF_LE` / `SPI_REF_MOSI` / `SPI_REF_SCK` vs. `REF_LOCK`）

对比截图中完全正常的 **`REF_LOCK`（`OUT` 端口）** 与发生导线穿模/重影的 **`ADF_LE`、`SPI_REF_MOSI`、`SPI_REF_SCK`（均为 `IN` 端口）**，定位出以下三个底层几何根因，并据此推广到所有图元：

1. **根因一：`createNetPort` 中 `IN` 与 `OUT`/`BI` 的锚点方向相反（导致导线贯穿五边形）**
   - **`OUT` 与 `BI` 端口**：`rot = 0` 时连接锚点 `(x, y)` 在**左端尾部**，五边形本体向右延伸（`[锚点(x,y)]──▷`，本体占 `x+10 .. x+40`）。放在芯片右侧、导线从左接入时，导线停在左端锚点，**零重合**（如 `REF_LOCK`）。
   - **`IN` 端口（相反！）**：`rot = 0` 时箭头同样向右指（表示信号从左进入电路 `▷──[锚点(x,y)]`），因此**连接锚点 `(x, y)` 在箭头右端尖部，五边形本体在锚点左侧（`x-40 .. x-10`）**！
   - 当把 `IN` 端口放在芯片**右侧**且仍传 `rot = 0` 时，五边形落在了锚点左侧的来线路径上，导致从左向右的绿色导线**直接贯穿整个红色五边形**才到达右端锚点（同理，`IN` 端口放在芯片**左侧**若误传 `rot = 180`，五边形也会翻到右侧压住导线）。
   - **正确方向表**：
     - 模块**右侧**（来线从左向右接入）：`OUT` / `BI` 用 **`rot = 0`**；`IN` 必须用 **`rot = 180`**（`[锚点(x,y)]──◁`）。
     - 模块**左侧**（来线从右向左接入）：`OUT` / `BI` 用 **`rot = 180`**；`IN` 必须用 **`rot = 0`**（`▷──[锚点(x,y)]`）。
     - 模块**上方**（来线从下向上接入，本体朝上）：`OUT` / `BI` 用 **`rot = 90`**；`IN` 用 **`rot = 270`**。
     - 模块**下方**（来线从上向下接入，本体朝下）：`OUT` / `BI` 用 **`rot = 270`**；`IN` 用 **`rot = 90`**。

2. **根因二：导线穿过端口图形与共线分段触发双份重影标签（如 `SPI_REF_MOSI` / `SPI_REF_SCK`）**
   - 当导线因方向反置穿过 `IN` 端口内部，或将同一水平线拆成两段共线相连导线并在外段赋 `net` 时，EasyEDA 会把网络名传播到多段/多节点，产生上下错位重影（`SPI_REF_MOSI`）或前后双标签（`SPI_REF_SCK`）。
   - 当含 T 型交点（如 `ADF_LE` 的上拉电阻节点）到端口锚点的净距过短时，自动居中的网络名会撞上五边形左缘或 T 交点红点。

3. **根因三：10-unit 密集引脚水平直出时垂直净空不足 + 相邻电源符号间距偏紧**
   - `NetPort` 五边形高约 `11 units`（`y ± 5.5`），网络名文字高约 `10–12 units`。相邻 `10 units` 间距引脚若不做 Y 向阶梯拉开，下一行的文字极易顶到上一行的导线或五边形底边。
   - 左上角 `5VA_REF` 与 `3V3_REF` 等相邻 `Power` 符号若水平间距仅 `30 units`，文字极易紧贴甚至触碰相邻竖线。

## 2. 以此类推：提炼为通用防重合准则

将上述个案推广为适用于**所有单端符号（`IN`/`OUT`/`BI` 端口、`Power`、`GND`、单端连接器、测试点）、双端/多端器件、导线与文字**的 4 条几何硬约束：

1. **通用“本体背离来线”包围盒铁律（BBox Away-From-Wire Invariant）**：
   - 任何图元的电气连接点 `(x, y)` 接入导线时，其符号图形包围盒 `getPrimitivesBBox([id])` **必须完全位于来线反方向的外侧空白区**：
     - 导线从**左**接入 → `bb.minX >= x - 1`（本体严格向右延伸）；
     - 导线从**右**接入 → `bb.maxX <= x + 1`（本体严格向左延伸）；
     - 导线从**下**接入 → `bb.minY >= y - 1`（本体严格向上延伸）；
     - 导线从**上**接入 → `bb.maxY <= y + 1`（本体严格向下延伸）。
   - 凡违反该不等式者（无论 `IN`/`OUT` 端口、电源、地或连接器），100% 发生导线穿模，必须立即旋转修正。
2. **走线通道零穿越铁律**：
   - 任何导线段（除目标连接引脚端点外）不得穿过任何芯片引脚（含 NC）、阻容本体、`NetPort` 五边形、`Power`/`GND` 符号或文字包围盒。
3. **标签、T 交点、密集端口与电源旗标的最小净空标准**：
   - **端口直连线**：严禁将同一直线拆成多段共线 wire（防双标签）；端口锚点与最近拐点/T 交点之间至少保留 **`max(90, 字符数 × 8 + 25)` units** 的纯水平无遮挡线段供文字居中渲染。
   - **10-unit 密集引脚扇出**：**优先采用正交 L 折线做 Y 向阶梯散开**，使相邻 `NetPort` 的垂直间距 **≥ 25–30 units**（折线传 `net = null` 并在拐点或最后水平段由端口自然带出单标签，或拉长末端水平段 ≥ 100 units）；若受空间限制只能保持 10-unit 行距做 X 向错位，外层端口必须拉出单根整线，且确保文字中心落在内层端口五边形最右端（`x_inner + 40`）外侧至少 **+40 units** 处。
   - **相邻 `Power` / `GND` 符号净空**：同高度或近高度（`Δy < 25`）的相邻 `Power` 旗标水平间距 **≥ `max(70, 字符数 × 8 + 20)` units**；`Power`/`GND` 竖直支线与相邻平行信号竖线间距 **≥ 25 units**。
4. **高清局部裁切终检（Zoomed Crop Gate）**：
   - 整页缩略图无法看清 10-unit 级别的穿模与双标签；导出 ≥ 3200 px PNG 后，必须对 **IC 密集引脚扇出区、NetPort 集中区、多电源引出区** 做局部放大检查，确认零穿模后再结项。
