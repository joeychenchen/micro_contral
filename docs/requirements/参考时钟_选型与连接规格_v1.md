# NV 微波源 · 参考时钟子系统 · 选型与连接规格 v1

> **用途**：给原理图绘制 agent（通过 MCP 操作 EasyEDA）使用的**绘图规格书**，同时作为设计留档。
> **适用范围**：参考时钟子系统 = 内部 100 MHz OCXO + 外部 10 MHz 锁相 + 校准 DAC + 时钟整形扇出 + 10 MHz 参考输出。
> **需求依据**：`微波源设计要求1009` §1（参考时钟、内部参考准确度、状态指示）、§5（两通道共用参考）、§6.1（10MHzREFIN / 10MHzREFOUT）。
> **日期**：2026-11-12

---

## 0. 给绘图 agent 的规则（必读）

1. **引脚一律按"引脚名"连接，不要按引脚号。**本文只有 OCXO（U18）的引脚号来自规格书，可以直接用；其他器件的引脚号以 EasyEDA 库符号和器件手册为准。库符号的引脚名和本文对不上时，**停下来报告，不要猜**。
2. 标了 **[待核实]** 的型号或数值：照常放置，但在器件旁边加文本注释 `[待核实]`。
3. **网络名严格使用本文 §6 网络表中的名字**。跨页连接用网络标签（Net Label），不要画长导线。
4. 现有电路（U18、L19、C81–C83、`5vosc`）**保留**，只按 §5.1 修改 R38 相关的连接。
5. 无源器件默认 0402；电源去耦和大容量电容按 §5 写的值和封装放置。
6. 建议拆成一页或两页原理图："REF_CLOCK"（§5.1–§5.6）和 "CLK_DIST"（§5.7–§5.8）。
7. 画完后导出网表，逐条对照 §6，输出一份差异清单。

## 1. 设计目标

| 项目 | 目标 | 实现方式 |
|---|---|---|
| 内部参考 | 100 MHz，校准后 ≤ ±0.1 ppm | OCXO + 16 bit DAC 调 VC，校准值存 Flash |
| 外部参考 | 接收 10 MHz，整机锁定到外部参考 | ADF4002 鉴相 → 环路滤波 → OCXO VC（锁相） |
| 下游时钟 | 不论内外参考，下游始终拿到 **OCXO 输出的 100 MHz** | 两种模式下只用一套 DDS/LMX 配置和一套校准表 |
| 参考输出 | 10 MHz，50 Ω | 100 MHz ÷10 后驱动输出 |
| 状态 | 参考锁定、外部参考在用 | ADF4002 MUXOUT 锁定检测 + LED + 上报给 H7 |
| 与主控的关系 | H7 只负责配置和监测，**不在时钟信号路径上** | H7 死机或复位时，环路保持锁定；模拟开关默认选内部 |

## 2. 架构

```
                          U18 Vref(4V) ──►[U22A 缓冲]──► U21 DAC VREF
 H7 SPI ──► U21 DAC8551 ──►[RC 1.6Hz]── DAC_VC ──┐
                                                  ├─► U23 TS5A3159 ─► VC_SW ─►[U22B 缓冲]─► OCXO_VC ─► U18 Pin1 VC
 10MHzREFIN ─►[50Ω 端接/ESD/钳位]─► U20 ADF4002 ─CP─►[环路滤波]─ LF_OUT ┘   ▲ IN = REF_SEL（下拉=内部）
 (J_REFIN)          │                   ▲ RFin(N=10)                                           │
                    └─►[U24 施密特]─► EXTREF_DET（给 H7 计频）                          VC_MON ─► H7 ADC
                                        │
 U18 Pin4 Fout ─►[50Ω 端接]─► U25 LTC6957 ─► U26 扇出 1:8 ─┬─ OUT0 ─► DDS-A REFCLK
  (正弦 8–12 dBm)                         (LVDS)           ├─ OUT1 ─► DDS-B REFCLK
                                                           ├─ OUT2 ─► LMX-A OSCin
                                                           ├─ OUT3 ─► LMX-B OSCin
                                                           ├─ OUT4 ─► U20 ADF4002 RFin（反馈）
                                                           ├─ OUT5 ─► U27 LVDS→CMOS ─► U28 ÷5 ─► U29 ÷2 ─► U30 驱动 ─► 10MHzREFOUT
                                                           └─ OUT6/7  备用（端接或关闭）
```

### 2.1 两种工作模式

| 模式 | REF_SEL | U23 选通 | VC 由谁决定 | ADF4002 CP |
|---|---|---|---|---|
| 内部（**上电默认**） | 低 | NC = DAC_VC | DAC 校准值 | 三态（寄存器设置） |
| 外部 | 高 | NO = LF_OUT | 锁相环自动调节 | 正常工作 |

## 4. 电源规划

| 电源网络 | 电压 | 来源 | 负载 | 注意 |
|---|---|---|---|---|
| `5vosc` | 5.0 V | 现有 | U18 OCXO | **上电电流约 0.7 A**（启动功率 < 3.5 W），稳态约 0.3 A。确认 LDO/DC-DC 和 L19 的额定电流 ≥ 1 A |
| `5VA_REF` | 5.0 V | U32 | U20 VP、U21 VDD、U22 V+ | 和 `5vosc` **分开**，避免 OCXO 加热电流的波动耦合到 VC |
| `3V3_REF` | 3.3 V | U31 | U20 AVDD/DVDD、U23、U24、U25、U26、U27–U30 | 时钟器件各自加磁珠和 100 nF + 1 µF 去耦 |

模拟地和数字地共用一个地平面。OCXO、环路滤波和 VC 缓冲放在同一块安静的区域，下面不走数字线。

## 5. 分块电路与连接

### 5.1 OCXO（U18，在现有电路上修改）

| U18 引脚 | 名称 | 连接 |
|---|---|---|
| 1 | VC | 网络 `OCXO_VC`。**断开它和 R38 抽头的直接连接** |
| 2 | VREF（4 V） | 网络 `OCXO_VREF` → U22A 同相输入；同时接 R38 的一端 |
| 3 | GND | GND |
| 4 | FOUT | 网络 `OCXO_RF` → §5.7 |
| 5 | VCC | `5vosc`（现有 L19、C81–C83 不动） |

R38 改为调试备用：R38 一端接 `OCXO_VREF`，另一端接 GND，抽头经 **R39 = 0 Ω（DNP）** 接到 `OCXO_VC`。正常装配时 R39 不焊；DAC 电路出问题时焊上 R39、取下 U22，就能退回手动调节。

| 元件 | 连接 | 值 |
|---|---|---|
| J_REFIN | 中心针 → `EXTREF_IN`，外壳 → GND | BNC |
| D2 | `EXTREF_IN` ↔ GND | 低电容 ESD |
| R40 | `EXTREF_IN` ↔ GND | 49.9 Ω（50 Ω 端接） |
| C40 | `EXTREF_IN` → `EXTREF_AC` | 100 nF |
| D1（BAV99） | `EXTREF_AC` 钳位到 `3V3_REF` 和 GND | — |
| R41 | `EXTREF_AC` → `ADF_REFIN` | 100 Ω，串联限流 |
| C41 | `EXTREF_IN` → `EXTREF_DET_AC` | 100 nF |
| R42 / R43 | `EXTREF_DET_AC` 分别接 `3V3_REF` 和 GND | 各 10 kΩ，偏置到 1.65 V |
| U24 74LVC1G14 | A ← `EXTREF_DET_AC`，Y → `EXTREF_DET`（给 H7 定时器 ETR 计频） | 3.3 V 供电 |

输入电平按 0 到 +13 dBm 正弦或 3.3 V CMOS 设计 **[待核实：ADF4002 REFIN 的输入幅度上下限]**。

### 5.4 环路滤波（无源二阶 + 一级附加极点）

```
 LF_CP ──┬────────────┬──[R48 10k]──┬── LF_OUT ──► U23 NO
         │            │             │
       [C47]        [R47]         [C49]
       0.33µF        22k           22nF
         │            │             │
        GND         LF_Z           GND
                      │
                    [C48]
                    2.2µF
                      │
                     GND
```

| 元件 | 连接 | 值 | 介质 |
|---|---|---|---|
| C47 | `LF_CP` – GND | 0.33 µF | 薄膜或 C0G/NP0（0.33 µF 的 C0G 可以用 1206 或 1210 封装） |
| R47 | `LF_CP` – `LF_Z` | 22 kΩ | 1 % |
| C48 | `LF_Z` – GND | 2.2 µF | **薄膜电容**（不能用电解电容，尽量不用 X7R） |
| R48 | `LF_CP` – `LF_OUT` | 10 kΩ | 1 % |
| C49 | `LF_OUT` – GND | 22 nF | C0G |

设计依据（初值，需要用 ADIsimPLL 复核）：Kv = 50 Hz/V（手册给的是最小值：0–4 V 对应 ≥ ±1 ppm），N = 10，PFD = 10 MHz，ICP = 0.625 mA，环路带宽约 10 Hz，相位裕量约 50°；附加极点在约 720 Hz。实际 Kv 比最小值大时，带宽会略大，不影响稳定性。

### 5.6 VC 选择、缓冲和回读（U23、U22B）

| 元件 / 引脚 | 连接 | 值 |
|---|---|---|
| U23 NC | `DAC_VC` | IN 为低时选通，对应内部模式 |
| U23 NO | `LF_OUT` | IN 为高时选通，对应外部模式 |
| U23 COM | `VC_SW` | |
| U23 IN | `REF_SEL`，R51 = 100 kΩ 下拉到 GND | **上电和 H7 复位时默认选内部** |
| U23 V+ | `3V3_REF` [待核实：3.3 V 供电时能否通过 0–4 V 信号；不行就改用 5 V 供电，或换成 5 V 规格的开关] | |
| U22B +IN | `VC_SW` | |
| U22B −IN、OUT | 短接，输出接 `VC_BUF` | 单位增益跟随 |
| R52 | `VC_BUF` – `OCXO_VC` | 100 Ω，隔离运放输出和负载 |
| C52 | `OCXO_VC` – GND | 100 nF |
| R53 / R54 | `VC_BUF` → R53 → `VC_MON` → R54 → GND | 各 10 kΩ（1:2 分压），`VC_MON` 接 H7 ADC，另加 C54 = 10 nF 到地 |

### 5.8 10 MHz 参考输出（U27–U30）

```
 CLK100_DIV_P/N ─► U27 SN65LVDS2 ─ CLK100_CMOS ─► U28 74LVC163 (÷5) ─ CLK20 ─► U29 74LVC1G74 (÷2) ─ CLK10 ─► U30 74LVC2G34 ×2 并联 ─► R60 ─► J_REFOUT
```

| 元件 | 连接 | 值 |
|---|---|---|
| U27 | A/B ← `CLK100_DIV_P/N`，R ← 100 Ω 端接，Y → `CLK100_CMOS` | 3.3 V |
| U28 74LVC163 | CLK ← `CLK100_CMOS`；接成 0→4 循环（÷5），QC（或进位输出）→ `CLK20` | 具体接法：QC 经反相送到 LOAD（同步置数为 0），或按手册的 ÷5 电路 [待核实] |
| U29 74LVC1G74 | CLK ← `CLK20`；D 接 Q̄；Q → `CLK10` | 50 % 占空比 |
| U30 74LVC2G34 | 两个输入都接 `CLK10`，两个输出并联 → `REFOUT_DRV` | 并联是为了增加驱动电流 |
| R60 | `REFOUT_DRV` → `REFOUT_BNC` | 33 Ω（加上门电路的输出阻抗约等于 50 Ω 源阻抗） |
| C60（可选，DNP） | 输出端低通，把方波变成近似正弦 | 预留焊盘 |
| J_REFOUT | 中心针 ← `REFOUT_BNC`，外壳 → GND | BNC |

## 7. 固件配置要点（不画图，供 H7 驱动开发参考）

1. **ADF4002 寄存器**：R = 1；N = 10（[待核实：B 计数器的最小允许值]）；PD 极性 = 正（OCXO 是正斜率，无源滤波不反相）；ICP = 最小档 0.625 mA；MUXOUT = 数字锁定检测。
2. **内部模式**：CP 设为三态，`REF_SEL = 0`，DAC 写入 Flash 里存的校准值。
3. **切到外部**：`EXTREF_DET` 计频，确认约 10 MHz（误差 < 2 ppm）→ 关 RF → CP 恢复工作 → `REF_SEL = 1` → 等 `REF_LOCK` 有效并稳定约 5 s（环路带宽 10 Hz，捕获需要秒级时间）→ 下游 LMX 重新校准 → 开 RF。
4. **切回内部（无扰）**：读 `VC_MON`，换算出当前 VC → 把 DAC 写成同一电压 → 等约 5 s（RC 1.6 Hz 稳定）→ `REF_SEL = 0`。
5. **监测**：外部模式下 VC 超出 0.3–3.7 V，说明外部参考接近牵引极限（约 ±1 ppm）→ 报故障；`EXTREF_DET` 丢失或 `REF_LOCK` 失效 → 自动切回内部并上报。
6. **校准**：内部模式下，用外部标准源（或锁定状态下的 VC 读数）反推出 DAC 值，写入 Flash。OCXO 老化 ≤ ±200 ppb/年，**建议每半年校准一次**。
7. **预热**：上电约 5 分钟后，"预热完成"状态才置位（手册：开机 5 分钟时相对 1 小时值 ≤ ±0.1 ppm）。

## 8. 布局要点

1. U18、U20、环路滤波、U21–U23 放在同一块区域，地平面完整，下方和周围不走数字线和开关电源走线。
2. `LF_CP`、`LF_Z`、`OCXO_VC` 这几个高阻抗节点**走线尽量短**，四周包地，远离 SPI 线。
3. `OCXO_RF` 是 50 Ω 正弦线，到 R55 和 U25 的走线短而直，按 50 Ω 阻抗控制。
4. 所有 LVDS 对按 100 Ω 差分走线，等长；到 DDS 和 LMX 的两对时钟布线对称（A、B 两链对称）。
5. 分频电路（U27–U30）和 REFOUT 是方波边沿噪声源，放在离 OCXO 和 LMX 时钟线较远的地方，单独做电源去耦。
6. OCXO 外壳会发热，留出空气流通的空间，远离 PA 等热源。
